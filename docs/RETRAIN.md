# Реальное дообучение модели

Важно: веб-приложение уже работает без обучения и использует совместимый checkpoint. Но для реального улучшения классификации нужен размеченный датасет.

## 1. Подготовь данные

Используй HAM10000 и/или свои **размеченные** клинические фотографии. HAM10000 содержит 10 015 дерматоскопических изображений 7 классов, но распределение сильно неравномерное: NV 6705 против AKIEC 327. Поэтому в `train.py` используется `WeightedRandomSampler` и аугментации. HAM10000 не равен обычным фотографиям телефона.

Сделай структуру:

```text
data/
  train/
    akiec/
    bcc/
    bkl/
    df/
    mel/
    nv/
    vasc/
  val/
    akiec/
    bcc/
    bkl/
    df/
    mel/
    nv/
    vasc/
```

Не допускай, чтобы фотографии одного и того же поражения попали одновременно в train и val.

## 2. Установка

```bash
pip install -r requirements.txt
```

## 3. Обучение

На GPU-машине:

```bash
python train.py --data data --epochs 12 --batch-size 32 --lr 0.0002
```

Получится:

```text
model/model.pth
```

## 4. Деплой

Положи этот `model/model.pth` в корень проекта перед commit/push. Удали правило `model/model.pth` из `.gitignore`, если хочешь хранить веса в Git LFS; для больших файлов лучше использовать внешнее хранилище и `MODEL_WEIGHTS_URL`.

## Почему нельзя просто обучить на одной ошибочно классифицированной фотографии

Одна фотография не содержит достаточно информации для обучения модели и может привести к memorization/overfitting. Для улучшения именно телефонных фотографий нужны десятки/сотни/тысячи корректно размеченных клинических снимков, желательно с разными телефонами, освещением и локализациями.
