# Model notice

MVP model:
iamhmh/derm-cnn-ham10000

Dataset:
HAM10000

Classes:
- Actinic keratoses
- Basal cell carcinoma
- Benign keratosis
- Dermatofibroma
- Melanocytic nevus
- Vascular lesion
- Melanoma

The model card reports 0.99 accuracy / macro F1 on its official HAM10000 split, but this should NOT be interpreted as real-world clinical accuracy. The model itself notes that it is trained on dermatoscopic images and performance on clinical camera photos is not guaranteed.
