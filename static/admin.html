CLASS & DATASET MANAGEMENT

Добавляй заболевания
через панель управления

Создать класс легко. Чтобы модель его распознавала, нужны проверенные размеченные фото и новое обучение.

1. Доступ администратора

Не публикуй токен и не коммить его в GitHub. Если токен не настроен в Render, админские действия отключены.

2. Создать заболевание

Создание класса меняет реестр, но не добавляет знания в веса модели. Следующий обязательный шаг — загрузить изображения и переобучить.

3. Загрузить размеченные фото

Загружай только изображения, для которых есть право использования и корректная экспертная метка. Для хорошего обучения нужны разнообразные примеры каждого класса, а не один-два снимка.

Реестр классов

Нажми «Загрузить классы».

4. Переобучение модели

Для безопасности обучение не запускается на публичном Render. Скачай примеры в data/dataset/<class_id>/, затем локально запусти:

python -m venv .venv
# активируй .venv, затем:
pip install -r requirements.txt
python train.py --data data/dataset --epochs 8

Скрипт создаст model/custom_model.pth. Проверь метрики и независимый тестовый набор, затем добавь веса и конфигурацию в защищённое хранилище/деплой. В Render без постоянного диска локальные загрузки и веса могут исчезнуть при redeploy.
